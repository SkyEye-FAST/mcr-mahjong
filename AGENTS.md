# mcr-mahjong

- Single-module Kotlin/JVM library, Java 17 bytecode/API baseline.
- Keep Minecraft, native runtimes and Python out of the library and normal tests.
- Preserve the pinned upstream algorithm and default evaluation as the C++ parity baseline.
  Public scoring uses the explicitly versioned WMO baseline in COMPATIBILITY.md.
  Keep sourced rule adjustments in StandardMcr, evaluated before candidate selection.
  Do not rewrite decomposition/shanten or silently change either baseline.
- Public input validation may be stricter than C++; document the boundary.
- Keep routine regression tests deterministic and fast. Native differential tests
  are explicit opt-in developer checks, never a prerequisite for ordinary builds.
- Preserve MIT attribution. Update NOTICE and fixtures together when changing upstream.
- Sign every commit. Do not modify sibling repositories.
- No formal version tag or public deployment until the rules review in
  COMPATIBILITY.md is resolved. Do not describe upstream defaults as universal MCR.
- Public ABI is generated by updateKotlinAbi and checked by build; never hand-edit
  the dump or regenerate it automatically in CI to conceal an incompatible change.
